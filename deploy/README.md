# Deployment

Use the Nginx template with real TLS paths and environment values supplied outside Git. Uvicorn listens only on `127.0.0.1`; Nginx is the public endpoint. The template overwrites `X-Forwarded-For` with Nginx's connected remote address; preserve that behavior and never expose Uvicorn publicly, so inquiry rate limits cannot be spoofed. `/inquiry` is served through the React SPA fallback. Set every `TODO_*` value during deployment. Apply `alembic upgrade head` only after taking and verifying a local SQLite backup; this adds the persistent public inquiry attempt log. The public `POST /api/inquiry` API stores the submitted client, wedding, and service-party details; it requires contact consent transiently and sends no email. It allows three submissions per IP per rolling hour except in `APP_ENV=development`. Required and optional fields, planning slugs, mappings, and date rules are documented in the root README. Enable the cleanup timer after deployment. Off-host backups are intentionally deferred; follow `PRODUCTION_BACKUP_FUTURE.md` before adding them.
